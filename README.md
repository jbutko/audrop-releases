# Audrop

Official macOS downloads and updates for Audrop.

## Installation

1. Download the Audrop `.dmg` from [Releases](https://github.com/jbutko/audrop-releases/releases).
2. Open the disk image and drag **Audrop** onto **Applications**.
3. Launch Audrop from Applications, then eject the disk image.

Requires macOS 14.2 or later.

This repository contains distribution files. The application source code is maintained privately.
